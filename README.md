# 🚀 Universal Productive Costing System (UPCS)

Sistema integral de gestión de costos estándar diseñado para la producción industrial y el sector agropecuario (activos biológicos). Este sistema permite un control preciso de insumos, conversiones de unidades y hojas de vida financiera para lotes productivos.

## ✨ Características Principales

- **Gestión de Unidades de Medida**: Soporte para unidades industriales y biológicas (ej. Cabeza, Pieza, Peso Vivo).
- **Módulo de Conversiones**: Factores dinámicos entre unidades origen y destino (ej. 1 kg PV -> 0.7 kg PG).
- **Catálogo de Insumos**: Administración de materiales con costos estándar y etapas productivas.
- **Carga Masiva Inteligente**: Importación de inventarios vía CSV con validación automática y sellado de fecha.
- **Diseño Premium**: Interfaz moderna, responsiva y orientada a la experiencia de usuario (UX/UI).

## 🛠️ Tecnologías Utilizadas

**Frontend:**
- **React 18** + **Vite** (Rápido y moderno)
- **TypeScript** (Seguridad en el código)
- **Tailwind CSS** (Estilos profesionales y dinámicos)
- **Lucide React** (Iconografía minimalista)
- **Axios** (Comunicación con el servidor)

**Backend:**
- **Node.js** + **Express**
- **PostgreSQL** (Base de datos relacional robusta)
- **PG Pool** (Gestión eficiente de conexiones)
